# Dev Detective 🔍

**Dev Detective** is a clean and responsive web app that helps users search for GitHub profiles by username. Built using HTML, CSS, and JavaScript, it fetches real-time data from the GitHub API and displays it in a user-friendly format.

## 🌐 Live Demo

👉 [Check out the live site](https://findgithubuser07.netlify.app/)

## ✨ Features

- 🔍 Search any GitHub user by their username
- 📊 View key profile details: name, bio, location, followers, public repos, etc.
- 🌙 Toggle between Light and Dark modes
- ⚡ Fast, responsive, and easy to use interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- GitHub API
- Netlify (for deployment)
